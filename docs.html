🚀 The Twin-Engine Architecture

SignOS operates on two parallel GitHub repositories to allow risk-free development while maintaining stable operations.

🛠️ DEV Engine (signos-app)

The Sandbox. All new code is pushed here first. The API automatically detects updates here and logs them as vX.X (Dev) in the backend.

🟢 LIVE Engine (signos-live)

Production Only. Stable files are manually copied here. The API logs these as vX.X (Live). Sales staff are routed here automatically.

Physics Engines

Yard Signs

  • Bulk Trigger: Qty > 1100 switches cost basis.
  • Risk Buffer: 5% (SS) / 10% (DS).

Coroplast

  • Split Workflow: 4mm Direct vs 10mm Mount.
  • Sheet Opt: Calculates 4x8 yield.

ACM Signs

  • Shear vs CNC: Square cuts avoid router fees.
  • Stock Logic: Optimizes 4x8 vs 5x10 sheets.

Acrylic

  • Linear Feed: Costs based on 64" bed utilization.
  • Paint Engine: Calculated by SqFt + Setup.
