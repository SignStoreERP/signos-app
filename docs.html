How to use Calculators

Quoting a job is now a consistent 3-step process. No more looking through static price sheets.

  • 1
    Select Product

    Pick your module from the menu or dashboard.

  • 2
    Enter Variables

    Input size, quantity, and specific product options (single/double sided, thickness, finish).

  • 3
    Get Price

    The total updates instantly based on market-based curves.

How it Works

DATA

The Brain

A Master Data Sheet feeds all pricing logic. One change to material cost updates every calculator shop-wide instantly.

USER

Security & Roles

Defined user roles and 6-digit PINs control access. Admin can toggle modules ON/OFF or update logic via the Cloud Matrix.

COST

Physics Basis

Every product considers the real cost of material yield and various labor tasks (printing, weeding, routing).
