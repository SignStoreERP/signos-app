1. The Waterfall Architecture

SignOS uses a strict one-way flow of data to ensure consistency.

Level 1 (Masters): The Source of Truth. Defines raw costs (e.g., Ink = $0.16/sqft). Only Owners edit this.

↓

Level 2 (Products): The Context Layer. Combines Master data to build a product price (e.g., A Banner uses Ink + Vinyl + Grommets). Managers edit this.

↓

Level 3 (Frontend): The Calculator. Takes User Input (Qty 10) and multiplies it by Level 2 data. No math happens here.

2. Production Physics

Linear Print Logic (Roll/Hybrid)

Printers have a fixed width (64"). If a sign is 48x96, the system calculates print time based on feeding 8 linear feet through the machine, not just total square footage. This accounts for the physical carriage movement time.

Sheet Logic (Rigid)

For Coroplast and ACM, the system calculates how many full 4x8 sheets are required. Setup time and Load/Unload time are applied per sheet, not per small sign, to ensure accurate labor costing for batch runs.

3. Profit Guard & Risk

Every calculator includes a Risk Buffer (typically 15-20%). This is not profit; it is a cost reserve for mistakes, material flaws, and reprints. If the Net Profit drops below $0.00 on both In-House and Vendor tabs, a LOSS ALERT warning triggers on the screen.

Backend Variable Glossary

Use these prefixes to understand the variables in the Google Sheet.

Retail_

Customer-facing prices. (e.g., Retail_Price_Sign_SS).

Cost_

Internal manufacturing cost. (e.g., Cost_Ink_UV).

S365_ / Vend_

Wholesale pricing from Signs365. Used for the "Vended" tab comparison.

Time_

Standard production time in Minutes. (e.g., Time_Setup_Print = 15).

Rate_

Hourly cost of Labor or Machinery. (e.g., Rate_Operator = $25/hr).

Constraint_

Physical limits. (e.g., Constraint_Bed_Width = 64").
