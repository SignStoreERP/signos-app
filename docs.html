The Physics Engines

SignOS calculates costs based on physical manufacturing constraints. Each calculator uses a specific logic engine described below.

Yard Signs

  • Bulk Trigger: Qty > 1100 switches to discounted material cost.
  • Risk Buffer: 5% (SS) / 10% (DS) added to total cost.
  • Vendor Logic: 3-Tier lookup (1-9, 10-50, 51+) based on sheet count.

Custom Coroplast

  • Workflow Split: 4mm uses Direct Print (Flatbed). 10mm uses Vinyl Mount (Roll + Lam + Mount).
  • Sheet Optimization: Calculates cost based on 4x8 sheet yield.
  • Shipping: Applies S365 tiered shipping rates based on max dimension (24", 36", 48", Freight).

ACM / Metal

  • Smart Vendor: Compares "Price per SqFt" vs "Price per Sheet" and selects the cheapest option automatically.
  • CNC Logic: Adds 10 min setup + run time per unit if Contour Cut is selected.

Acrylic Flat Signs

  • Linear Nesting: Nests parts on 48x96 sheets to determine true material usage.
  • Paint Engine: Adds material cost + spray booth labor time.
  • Pass Counts: Adjusts print speed for 2nd Surface (White Ink) vs Standard.

Vinyl Banners

  • Width Constraint: >62" triggers "Oversized" warning and disables In-House.
  • Finishing: Calculates linear footage of Hem Tape and Grommet count (every 2ft).
  • Pocket Logic: Adds 4" material height allowance for pole pockets.

Decals & Stickers

  • Cut Logic: "Kiss Cut" (Plotter) vs "Thru Cut" (Hand/Shear).
  • Weeding Physics: "Complex" toggle increases labor time by 400% (2m vs 8m / sqft).
  • Freight Trigger: Orders >1000 sqft automatically trigger freight shipping costs.

Vehicle Wraps

  • Billing vs Production: Charges for surface area, but costs for panel overlaps + waste.
  • Fleet Engine: Dynamic looping checks for volume discounts (3+, 5+, 10+ vehicles).
  • Install Rate: "Simple" (Box Truck) = 25 sqft/hr. "Complex" (Van) = 10 sqft/hr.

Cut Vinyl

  • Complexity Factor: Toggles Weeding time from 2m (Simple) to 10m (Complex) per sqft.
  • Masking: Adds specific labor time and Transfer Tape material cost.
  • Color Database: Includes full Oracal 651/751 library.
