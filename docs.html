The Physics Engines

SignOS calculates costs based on physical manufacturing constraints, not just square footage. Below is the logic breakdown for each module.

Yard Signs (Coroplast)

  • Bulk Trigger: If Qty > 1100, the system switches material cost to Cost_Blank_Bulk.
  • Risk Buffer: Adds 5% waste for single-sided, 10% for double-sided print runs.
  • Production: Assumes HP R1000 printing 3-up on the bed.
  • Vendor Logic: Pulls from 3 distinct tiers (1-9, 10-50, 51+) based on total sheet count.

ACM / Metal Signs

  • Smart Vendor Comparison: Simultaneously calculates "Price per SqFt" and "Price per Sheet" from Signs365 and automatically selects the cheaper option for the quote.
  • CNC Routing: Adds setup time (10 min) + run time (2 min/unit) if "Contour Cut" or "Holes" are selected.
  • Profit Guard: Triggers a "LOSS ALERT" if both In-House and Vendor margins are negative.

Acrylic Flat Signs

  • Paint Engine: If "Paint Background" is selected, adds material cost per sqft AND Paint Booth labor time (Mix + Spray).
  • Linear Nesting: Calculates print time by nesting parts onto a 48"x96" sheet virtual model.
  • Pass Count Physics:
    • 1st Surface (CMYK) = Fast (18 LF/hr)
    • 2nd Surface (CMYK+W) = Slow (4.9 LF/hr)
    • Blockout (CMYK+W+K+W+CMYK) = Very Slow (3.2 LF/hr)

Vinyl Banners

  • Width Constraint: If the shortest dimension exceeds 62", the system forces "Oversized" warnings and disables In-House costing.
  • Finishing Math: Calculates linear footage of Hem Tape and specific grommet counts (every 2ft) for accurate material costing.
  • Pole Pockets: Adds 4 inches of material to the height for calculation but charges a finishing fee per LF.

Vehicle Wraps

  • Billing vs. Production Area:
    • Billing SqFt: Actual surface area of the vehicle.
    • Production SqFt: Includes panel overlaps (1") and waste. This is used for cost calculation.
  • Fleet Discounts: Dynamic loop checks Tier_X_Qty to apply volume discounts for multi-vehicle projects.
  • Install Complexity: "Simple" (Box Truck) uses 25 sqft/hr install speed. "Complex" (Van) uses 10 sqft/hr.
